The palette is intentionally small. --fg and --bg provide the stark contrast. --accent (blue) is the only chromatic "brand" color and drives all structural markers. --highlight (neon yellow-green) is used sparingly to draw the eye to interactive text. Additional hues should be avoided — if you need another color, question the component before adding the token.
Color Pairings
fg on bg — Primary reading
bg on fg — Inverted (active nav, primary btn)
highlight-fg on highlight — Inline links
bg on accent — Link hover, markers
Never set text directly in --accent on --bg at small sizes — the blue is saturated enough to feel straining. Use it as a background or as a small structural element (markers, borders). For text-level emphasis, use --highlight as a background behind --highlight-fg text.
Usage Rules
  • Use --fg / --bg for all body text. No grays for body copy.
  • Use --muted only for metadata: dates, labels, secondary info. Never for body paragraphs.
  • Use --accent for structural markers (the blue squares) and interactive hover states. Not for body text.
  • Use --highlight for inline link backgrounds and text-level callouts. Always pair with --highlight-fg text (dark in both themes).
  • Use --rule for light dividers and borders. Use --fg for heavy/structural rules (header, footer).
  • Use --danger only for destructive actions. Do not use for decorative purposes.

Typography Rules
  • Base font size is 16px. Line height is 1.6.
  • Max reading width is 55ch. Body text should never exceed this.
  • All labels, nav items, and metadata are uppercase with letter-spacing. Body text is never uppercase.
  • Use font-weight: 700 for labels and headings. Use 600 for interactive text (links, nav, buttons). Use 400 for body copy.
  • Letter-spacing increases as size decreases: 0.08em at 1.5rem, 0.12em at 0.75rem. Minimum font size is 0.75rem (12px). Most text should be 1rem (16px) or larger.
  • Only metadata (dates, labels, tags, captions) drops below 1rem. Body copy, lists, cards, inputs, notes, and blockquotes all render at 1rem+.

05 — Layout Principles

  • Single column, max-width 680px, centered.
  • Left-border rails (2px solid --rule) to group related content. The rail is the primary structural device.
  • Blue square markers (12×12px --accent) introduce each section. They are the visual anchor.
  • Heavy rules (2px solid --fg) for structural boundaries: header bottom, footer top. Light rules (1px --rule) for content separators within sections.
  • No rounded corners anywhere. No shadows. No gradients.
  • Transitions are 0.1s for interactive states. No easing — linear or step. No animation for non-interactive elements.
  • Mobile: the layout is already single-column. Reduce page padding to 1rem below 480px.
